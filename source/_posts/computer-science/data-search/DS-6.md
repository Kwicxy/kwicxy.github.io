## 1. 文摘数据库概述

文摘数据库主要提供文献题录、摘要、主题词、分类号、引文等信息。它不一定直接提供全文，但能帮助用户发现高质量文献并追踪学术关系。

与全文数据库相比：

| 项目 | 文摘数据库 | 全文数据库 |
| - | - | - |
| 主要内容 | 题录、摘要、索引、引文 | 文献全文 |
| 核心价值 | 发现文献、评价影响、追踪引用 | 阅读和下载全文 |
| 典型代表 | SCI、EI、INSPEC、CA | ScienceDirect、Springer Link |

## 2. SCI 与 Web of Science

SCI（Science Citation Index）是国际公认的综合性科学引文索引工具，网络版常通过 Web of Science 平台检索。

### SCI 特点

- 收录范围广。
- 选刊严格。
- 编制方式独特。
- 权威性高。
- 适合引文追踪和学术影响分析。

### Web of Science

Web of Science 集成高质量学术信息资源、分析工具和文献管理功能，支持：

- 主题检索。
- 作者检索。
- 来源出版物检索。
- 被引参考文献检索。
- 高级检索。
- 引文分析。

### 被引参考文献检索

适合解决：

- 某篇论文被引用多少次。
- 哪些文献引用了某篇经典论文。
- 某一研究成果的后续影响。

检索要素通常包括：

- 被引作者。
- 被引著作。
- 被引年份。
- 题名关键词。

## 3. EI Compendex

EI（The Engineering Index）创刊于 1884 年，是工程技术领域的重要综合性检索工具。

网络数据库通常通过 Engineering Village 平台检索。

### EI 检索方式

- 快速检索。
- 专家检索。
- 叙词检索。
- 字段限定检索。

### 常见字段和限定条件

- 检索词。
- 检索字段。
- 布尔逻辑算符。
- 文献类型。
- 文献处理类型。
- 语种。
- 时间范围。
- 排序方式。

### 适用场景

- 工程技术论文检索。
- 机械、材料、电子、计算机、土木、能源等领域文献发现。
- 查找工程领域高质量期刊和会议论文。

## 4. ISI Proceedings / CPCI

会议文献是学术文献的重要组成部分。ISI Proceedings 收录会议录资料，是了解会议论文的重要检索工具。

现在相关资源通常整合在 Web of Science 核心合集中的 CPCI：

| 类型 | 全称 | 说明 |
| - | - | - |
| CPCI-S | Conference Proceedings Citation Index-Science | 科学技术会议录引文索引 |
| CPCI-SSH | Conference Proceedings Citation Index-Social Science & Humanities | 社会科学与人文会议录引文索引 |

适合查找最新会议成果、前沿研究和学术会议论文。

## 5. INSPEC

INSPEC 是英国《科学文摘》的网络版数据库，覆盖物理、电气、电子、计算机、控制、通信与信息技术等领域。

### 覆盖范围

- 理论与应用物理。
- 电气与电子工程。
- 计算机科学。
- 控制技术。
- 通信与信息技术。
- 生产与制造工程。
- 光学、材料、核能、交通、地理、生物医学工程等相关领域。

### 检索方式

- 简单检索。
- 高级检索。
- 字段限定。
- 布尔逻辑组合。
- 时间范围限定。

## 6. 化学文摘 CA 与 SciFinder

CA（Chemical Abstracts）由美国化学文摘社 CAS 编辑出版，是化学化工领域重要检索工具。

SciFinder 是其重要网络检索平台。

### SciFinder 资源

- CAPLUS。
- CAS REGISTRY。
- CASREACT。
- CHEMCATS。
- CHEMLIST。
- MEDLINE。

### 检索类型

- 文献检索。
- 物质检索。
- 结构检索。
- 反应检索。
- 物质名称检索。

适用于化学物质、反应、结构、文献和供应信息检索。

## 7. 生物学文摘 BA 与 BIOSIS Previews

BA（Biological Abstracts）是生命科学领域重要文摘检索工具。

BIOSIS Previews 覆盖：

- 生物学。
- 生物化学。
- 生物技术。
- 植物学。
- 医学。
- 药理学。
- 动物学。
- 农业。
- 兽医学。

支持简单检索、高级检索、结果管理和检索历史保存。

## 8. 文摘数据库检索流程

1. 明确学科领域，选择合适数据库。
2. 将课题拆分为核心概念。
3. 选择字段：主题、题名、作者、机构、来源、年份等。
4. 使用布尔逻辑和限定条件构造检索式。
5. 查看题录、摘要、主题词和分类。
6. 利用分析、精炼、排序功能筛选结果。
7. 根据 DOI、全文链接或馆藏服务获取全文。
8. 保存检索历史，必要时创建提醒或 RSS。
