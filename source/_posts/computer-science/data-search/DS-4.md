## 1. 中国知网 CNKI

CNKI 是国内最常用的综合性中文学术资源平台之一。

### 主要资源

- 中国学术期刊网络版。
- 中国博士学位论文全文数据库。
- 中国优秀硕士学位论文全文数据库。
- 中国重要会议论文全文数据库。
- 中国重要报纸全文数据库。
- 年鉴、专利、标准、成果、图书、法律法规、政府文件等。

### 检索入口

| 入口 | 用途 |
| - | - |
| 文献检索 | 查找期刊、学位论文、会议、报纸等文献 |
| 知识元检索 | 查找百科、词典、手册、工具书、统计数据等 |
| 引文检索 | 查找被引文献、引用关系和学术影响 |

### 检索方式

- 一框式检索。
- 高级检索。
- 专业检索。
- 作者发文检索。
- 科研基金检索。
- 句子检索。
- 来源期刊检索。

### 结果处理

- 按发表时间、相关度、被引频次等排序。
- 按学科、发表年度、来源、作者、机构等分组筛选。
- 查看题录、摘要、关键词、参考文献和引证关系。
- 获取 PDF、CAJ 等全文。

## 2. 万方数据知识服务平台

### 主要资源

| 类型 | 内容 |
| - | - |
| 学位论文 | 硕博士论文 |
| 学术期刊 | 中文期刊论文 |
| 会议论文 | 国内外会议文献 |
| 外文文献 | 外文题录和部分全文 |
| 专利 | 中外专利 |
| 标准 | 中外标准 |
| 科技成果 | 科技项目与成果信息 |
| 其他 | 地方志、法律法规、机构、专家等 |

### 检索功能

- 直接检索。
- 跨库检索。
- 高级检索。
- 经典检索。
- 专业检索。

### 结果显示

- 可按相关度、新论文、经典论文、出版时间、被引次数等排序。
- 可按学科、年份、期刊、相关学者等分组。
- 支持查看题录、摘要和全文。

## 3. 维普期刊资源整合服务平台

### 主要资源

- 中文科技期刊数据库。
- 中文科技期刊数据库引文版。
- 外文科技期刊数据库。
- 中国科学指标数据库。
- 中国科技经济新闻数据库。

### 主要功能

- 期刊文献检索。
- 文献引证追踪。
- 搜索引擎服务。
- 高级检索。
- 查看题录、文摘和全文。

## 4. 超星数字图书馆与读秀学术搜索

### 超星数字图书馆

主要用于电子图书检索和阅读，支持：

- 普通检索。
- 分类检索。
- 高级检索。
- 图书在线阅读和部分章节获取。

### 读秀学术搜索

读秀是面向学术资源的搜索平台，可检索：

- 图书。
- 期刊。
- 学位论文。
- 会议论文。
- 报纸。
- 文档资源。

读秀常用于发现图书线索、目录、部分原文和馆藏获取路径。

常见资源包括：

## 6. 中文数据库检索通用流程

```text
分析课题 -> 选择数据库 -> 选择检索字段 -> 构造检索式 -> 限定条件 -> 检索 -> 筛选结果 -> 获取全文
```

### 示例：检索“会计准则与公司治理”核心期刊论文

1. 选择数据库：CNKI 中国学术期刊网络版。
2. 确定时间：2010-2016 年。
3. 限定来源：核心期刊。
4. 选择字段：篇名、关键词、主题等。
5. 构造检索式：会计准则 AND 公司治理。
6. 选择精确或模糊检索。
7. 按发表时间、相关度或被引频次筛选。
8. 阅读题录、摘要并获取全文。

### 示例：检索专利

检索专利时要注意：

- 申请人。
- 发明名称。
- 摘要。
- 申请号或公开号。
- 申请日期。
- 专利类型。

## 7. 数据库对比

| 数据库 | 主要优势 | 常见用途 |

| CNKI | 综合性强，引文和知识元功能丰富 | 中文期刊、学位论文、会议、报纸 |
