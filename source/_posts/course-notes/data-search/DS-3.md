## 1. 图书馆馆藏资源

图书馆馆藏资源是由图书馆收集、整理、加工、组织、保管、开发并供读者利用的文献信息资源总和。

### 馆藏实体资源

馆藏实体资源是图书馆在物理上拥有的资源，包括：

- 印刷型图书、期刊、报纸。
- 声像资料。
- 缩微资料。
- 光盘文献。
- 存储在本馆服务器或设备上的数据库资源。

### 馆藏网络虚拟资源

馆藏网络虚拟资源是图书馆不具有所有权但拥有使用权的外部电子资源，通常通过网络、数据库平台或授权访问方式提供。

例子：

- 订购的中外文数据库。
- 电子期刊平台。
- 电子图书平台。
- 外部学术资源服务。

## 2. 图书整序方法

图书馆通常按图书分类法组织馆藏。图书排架依据是**索书号**。

### 索书号

索书号一般由两部分构成：

```text
索书号 = 分类号 + 书次号
```

- **分类号**：表示图书所属学科或主题类别。
- **书次号**：用于区分同一分类号下的不同图书。

排架规则：

1. 先按分类号排序。
2. 分类号相同，再按书次号排序。

:::warning
考试中常问“索书号的作用”。它不是随便贴在书脊上的编号，而是读者定位馆藏图书、图书馆组织排架的核心依据。
:::

## 3. OPAC 图书查检

OPAC（Online Public Access Catalogue）即联机公共查询目录，主要用于查询馆藏目录和读者个人借阅信息。

### OPAC 的作用

- 查询馆藏图书、期刊等目录信息。
- 查看图书馆是否收藏某书。
- 查看馆藏地点、索书号、借阅状态。
- 查询个人借阅信息。
- 办理预约、续借等服务。

### 常见检索方式

| 方式 | 用途 |
| - | - |
| 简单检索 | 输入题名、作者、关键词等快速查找 |
| 全文检索 | 在较广字段中检索相关内容 |
| 多字段检索 | 组合题名、作者、主题、出版社等字段 |
| 新书通报 | 查看图书馆新入藏资源 |
| 我的图书馆 | 查询个人借阅、预约、续借等信息 |

### 预约与续借

- **预约图书**：当图书已全部外借时，可通过 OPAC 办理预约，待归还后再借阅。
- **续借图书**：在图书临近归还日期时，可在允许条件下延长借期。

## 4. 图书馆服务

图书馆服务不仅是借书，还包括多种信息服务。

| 服务 | 说明 |
| - | - |
| 外借服务 | 提供图书借阅 |
| 阅览服务 | 提供馆内阅读空间和资料 |
| 网络信息资源服务 | 提供数据库、电子图书、电子期刊访问 |
| 信息咨询服务 | 解答资源利用和检索问题 |
| 文献检索与文献传递 | 帮助查找并获取文献 |
| 定题服务与信息推送 | 按用户主题长期跟踪信息 |
| 科技查新服务 | 为科研立项、成果鉴定等提供查新报告 |
| 用户辅导与培训 | 培训数据库和检索技能 |
| 复制、打印服务 | 支持文献复制和输出 |

## 5. 数字图书馆

数字图书馆是用数字技术处理和存储各种文献资源的图书馆，本质上是一种多媒体、分布式的信息系统。

### 特征

- 信息资源数字化。
- 服务网络化。
- 资源组织多媒体化。
- 查询和传播突破地域限制。
- 支持共建共享。

### 与传统图书馆的区别

| 维度 | 传统图书馆 | 数字图书馆 |
| - | - | - |
| 资源形态 | 纸质和实体资源为主 | 数字资源为主 |
| 服务空间 | 依赖物理馆舍 | 网络化、跨地域 |
| 检索方式 | 目录、索引、人工服务 | 数据库、搜索、导航 |
| 利用方式 | 到馆借阅或阅览 | 在线访问、下载、传递 |

## 6. 综合检索思路

查找图书馆资源时，可按以下步骤：

1. 明确检索目标：图书、期刊、论文、数据库还是电子资源。
2. 选择检索入口：OPAC、数据库导航、数字图书馆、统一发现系统。
3. 提取关键词：题名、作者、主题词、ISBN、出版社等。
4. 执行检索并筛选结果。
5. 记录索书号、馆藏地点、数据库链接或全文获取方式。
6. 必要时使用预约、续借、文献传递等服务。
