> 介绍国外电子图书、电子期刊、学位论文、专利和标准等全文数据库的资源范围与检索特点。

## 1. 电子图书数据库

### EBSCO eBook Collection

原名 OCLC NetLibrary，是较早的在线电子图书平台之一，提供多学科电子图书和有声电子图书。

特点：

- 覆盖学术阅读和普通阅读。
- 面向大学和研究型用户。
- 支持在线阅读和检索。

### Ebrary

Ebrary 提供来自多家出版社的电子图书，内容覆盖商业、社科、人文、历史、法律、教育、科技、语言文学、哲学、计算机、工程、医学等领域。

### Safari

Safari 电子图书偏重 IT 和计算机技术，由 O'Reilly 等出版商资源发展而来。

特点：

- IT 技术覆盖面广。
- 新书比例较高。
- 适合计算机、软件开发、网络技术等主题。

### Springer 电子图书

Springer 是重要的科技、技术、医学出版商。

覆盖领域：

- 化学与材料科学。
- 计算机科学。
- 地球与环境科学。
- 工程学。
- 数学。
- 物理与天文学。
- 医学与生命科学。
- 商业、经济、人文、社会科学等。

### Wiley 电子图书

Wiley 在线图书覆盖农业、商务、化学、计算机、工程、生命科学、数学统计、医学、物理、心理学、社会科学等领域。

### 不列颠百科全书

《不列颠百科全书》是权威综合性百科全书，适合查找概念、人物、事件、学科基础背景等事实型信息。

## 2. 电子图书检索方法

以 Springer Link 为例，常见方法包括：

- 简单检索：直接输入关键词。
- 高级检索：限定题名、作者、出版年、学科等字段。
- 学科浏览：按学科分类进入资源。
- 文献类型筛选：区分图书、章节、期刊论文等。
- 下载：根据平台权限下载章节或整本书。

## 3. 电子期刊数据库

### ScienceDirect

ScienceDirect 是 Elsevier 的核心全文数据库，覆盖多学科期刊，很多期刊被 SCI、EI 收录。

主要领域：

- 生命科学。
- 农业与生物。
- 化学与化工。
- 医学。
- 计算机。
- 地球科学。
- 工程、能源与技术。
- 环境科学。
- 材料科学。
- 数学、物理、天文。
- 社会科学。

### Springer Link 电子期刊

Springer Link 提供 Springer 出版的电子期刊全文，覆盖自然科学、工程技术、医学等领域。

### EBSCO ASP/BSP

| 数据库 | 侧重 |
| - | - |
| Academic Search Premier | 学术期刊综合资源 |
| Business Source Premier | 商业、管理、财经资源 |

### Wiley-Blackwell

Wiley-Blackwell 拥有大量高质量学术期刊，化学、生命科学、医学、材料学、工程技术等领域较有影响。

### Emerald

Emerald 以管理学期刊见长，也包含工程学全文数据库和若干文摘库。

### IEEE/IEE Electronic Library

IEL 是电气、电子、计算机、通信、自动化、应用物理等领域的重要全文数据库。

### Science 与 Nature

| 期刊 | 特点 |
| - | - |
| Science | 综合性顶级科学期刊，覆盖广泛科学研究 |
| Nature | 历史悠久的国际性科技期刊，报道重要科学突破 |

## 4. 电子期刊检索技巧

### 检索入口

- 快速检索。
- 简单检索。
- 高级检索。
- 专家检索。
- 按学科浏览。
- 按出版物名称浏览。

### 常用字段

- 题名。
- 作者。
- 摘要。
- 关键词。
- 期刊名。
- 出版年。

### 检索提示

- 短语检索使用引号，如 `"coral reef"`。
- 布尔运算符通常使用大写：`AND`、`OR`、`NOT`。
- 使用通配符扩大检索，如 `cardio*`。
- 作者检索通常优先使用姓氏。
- 可用同义词扩大检索，如 `kidney disease OR renal failure`。
- 停用词通常会被系统忽略，如 `of`、`the`、`in`。

## 5. 国外学位论文、专利与标准

虽然课件对本部分展开较少，复习时需要知道资源类型：

| 类型 | 用途 |
| - | - |
| 国外学位论文 | 查找博士、硕士论文，了解研究细节和综述 |
| 美国及欧洲专利数据库 | 查找技术方案、发明人、申请人、法律状态 |
| 国外标准数据库 | 查找国际标准、行业标准和技术规范 |

检索专利和标准时应关注编号、题名、申请人或发布机构、日期、分类号和法律状态。

## 6. 全文数据库使用流程

```text
明确主题 -> 选择平台 -> 选择字段 -> 构造检索式 -> 筛选结果 -> 阅读摘要 -> 获取全文 -> 导出引用
```

使用全文数据库时，不能只下载全文，还应记录：

- 题名。
- 作者。
- 来源期刊或图书。
- 出版年。
- DOI。
- 卷期页码。
- 引用格式。
