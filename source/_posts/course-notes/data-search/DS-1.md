> 介绍信息、知识、文献、情报、信息资源和信息素质等基础概念，建立信息检索课程的术语框架。

## 1. 信息社会与信息环境

### 信息

信息的含义很广。课程中可从以下角度理解：

- **信息论角度**：信息是用来消除不确定性的东西。
- **控制论角度**：信息是主体与外部世界相互作用和交换的内容。
- **本体论角度**：信息是事物运动状态及其变化方式。
- **认识论角度**：信息是主体感知或表述出来的客观事物属性。

信息不是物质，也不是意识，而是物质和意识之间的中介。信息依附于载体，但信息内容可以共享，且不随载体变化而改变其本质。

### 信息的特征

| 特征 | 含义 |
| - | - |
| 客观性 | 信息是现实世界中事物运动和状态的反映 |
| 普遍性 | 只要有事物及其运动，就存在信息 |
| 时效性 | 信息价值与时间密切相关，过时会贬值 |
| 传递性 | 信息可依附载体从信源传向信宿 |
| 共享性 | 同一信息可被多个用户使用，提供者不失去信息内容 |
| 增值性 | 信息经过加工、综合和利用后可产生更高价值 |

## 2. 知识、情报与文献

### 知识

知识是人类在实践中对客观事物的理性认识，是经过加工、系统化的信息。

信息与知识的关系：

- 信息是知识形成的来源。
- 知识是被理解、加工、组织后的信息。
- 信息不一定都能成为知识，只有被主体理解和吸收后才可能转化为知识。

### 情报

情报是对用户有特定价值、经过传递并能产生决策或行动影响的信息。它通常强调目的性、传递性和效用。

### 文献

文献是记录有知识的一切载体。文献不仅包括纸质图书、期刊，也包括电子文献、声像资料、数据库等。

文献的基本构成：

- 信息内容。
- 记录符号。
- 载体材料。
- 记录方式。

## 3. 信息、知识、情报、文献的关系

| 概念 | 关注重点 | 关系 |
| - | - | - |
| 信息 | 消除不确定性，反映事物状态 | 知识和情报的基础 |
| 知识 | 系统化、理性化的信息 | 来源于信息加工 |
| 情报 | 有目的、有价值、可传递的信息 | 强调用户需求和效用 |
| 文献 | 记录知识和信息的载体 | 是信息和知识传播的重要形式 |

可简化理解为：

```text
信息经过理解和加工形成知识；
知识或信息被记录在载体上形成文献；
对特定用户有价值并被传递利用的信息成为情报。
```

## 4. 信息资源

信息资源是经过开发、组织和利用后能够满足人类信息需求、产生价值的信息集合。

### 信息资源的构成

| 类型 | 说明 |
| - | - |
| 文献型信息资源 | 图书、期刊、论文、报告、专利、标准等 |
| 事实型信息资源 | 人物、机构、事件、法规、地名等事实资料 |
| 数据型信息资源 | 统计数据、实验数据、观测数据、参数等 |
| 多媒体信息资源 | 图像、音频、视频、动画等 |
| 网络信息资源 | 通过网络获取和传播的数字化信息资源 |

### 信息资源的特征

- **可开发性**：可通过采集、整理、加工形成可利用资源。
- **共享性**：可以被多人共同使用。
- **时效性**：价值受时间影响。
- **可传递性**：可借助载体和网络传播。
- **可增值性**：加工、整合和分析后价值提升。

## 5. 信息素质

信息素质是个体发现、获取、评价、组织、利用和创造信息的综合能力。

### 信息素质的构成

| 维度 | 含义 |
| - | - |
| 信息意识 | 能意识到何时需要信息 |
| 信息知识 | 了解信息资源、检索工具和信息组织方式 |
| 信息能力 | 能检索、筛选、评价、利用信息 |
| 信息伦理 | 能合法、规范、负责任地使用信息 |

### 信息素质的重要性

- 提高学习和研究效率。
- 避免重复劳动和低质量信息误导。
- 支持科学决策和创新。
- 帮助用户适应信息社会和数字环境。
